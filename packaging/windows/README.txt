Marquee for Windows
===================
1. Unzip this folder anywhere you have write access (not Program Files).
2. Double-click Start-Marquee.bat. Allow it through Windows Firewall if asked, so other devices can connect.
3. Your browser opens http://localhost:8080. Create the first account, then add your media folders (for example D:\Movies).

Data is kept in the "data" folder next to Start-Marquee.bat. To update, unzip the new version over the old one and keep "data".
To use your own ffmpeg, delete the "ffmpeg" folder and put ffmpeg/ffprobe on PATH.
